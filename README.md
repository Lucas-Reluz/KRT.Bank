# 🏦 Simulador de Operações Bancárias - ASP.NET MVC

Este projeto é uma aplicação **ASP.NET MVC** que simula operações bancárias básicas, incluindo:

- Criação de contas  
- Consulta de contas  
- Transferência via **Pix**  
- Remoção de contas  

---

## 🚀 Tecnologias Utilizadas

- **ASP.NET MVC com Razor**  
- **.NET 8**  
- **Amazon DynamoDB**  
- **xUnit** (testes automatizados)  
- **Newtonsoft.Json**  
- **Bootstrap 5**  

---

## ⚙️ Configuração e Execução

Para executar o projeto, siga os passos abaixo:

1. Configure suas credenciais da **AWS** para acesso ao **DynamoDB**.  
2. Ajuste o nome da tabela no arquivo `appsettings.json`.  
3. Execute o projeto com o comando:

   ```bash
   dotnet run
